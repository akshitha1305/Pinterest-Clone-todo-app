## Running the App
-cd to the server directory
  Run `npm install`
  Then cd to client
  Run `npm install`
- cd to project pinterest directory where client and server folders are present
   Then Run `npm run dev` to start the client and the server concurrently.
  
- Run `npm run client` to start the client.
- Run `npm run server` to start the server.
  
To execute our project, it is required to have Node.js version 20 or higher installed, along with a locally running instance of MongoDB.
